# Source References

This file defines stable source identifiers for source artifacts stored in this repository.

## Reference format

Use:

```text
Source: <SOURCE_ID>
Anchor: <section / theorem / PDF page>
```

Example:

```text
Source: SRC-TENET-PASS022-20260925
Anchor: PASS022 §244, PDF p. 109
```

A source reference identifies where a statement came from. It does not replace the original source artifact.
